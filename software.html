Installation

Install in three steps

1

Download and run the driver installer

Pick your system above — Windows (one installer covers every S68) or macOS (Apple silicon / Intel). Links are direct: no sign-up, no password.

2

Close other keyboard software, then follow the on-screen steps

Quit any other keyboard utility first so it cannot grab the device. Windows needs an administrator account. On macOS the app is signed and notarized by Apple — a normal double-click is enough.

3

Connect the keyboard with the included cable

Use the included USB-C to USB-A cable, then open SOTRUST software to set per-key actuation, Rapid Trigger and lighting. S68 connects with a cable only — there is no wireless mode.

Connection (S68)

The S68 is a wired keyboard. Connect it to your computer with the included USB-C to USB-A cable — no receiver, no pairing, no battery. Plug it in and it works immediately; the software is optional and only needed for customization.

  • Use a USB-C cable that supports data transfer — charge-only cables cannot be recognized.
  • If your computer only has USB-A ports, the included cable connects directly (it is C-to-A).
  • No 2.4G, Bluetooth or wireless mode; no receiver is included or needed.
FAQ

Frequently asked questions

Windows shows "Unknown publisher" — is it safe?
Our installer is digitally signed by SOTRUST. You can verify it in the file properties under Digital Signatures. Until the signed build is published, expand the SHA-256 checksum under the Windows download above and compare it with your downloaded file — if they match, the file is intact and unmodified.
Does the S68 support wireless or Bluetooth?
No. The S68 is a wired keyboard and connects only with the included USB-C to USB-A cable. There is no 2.4G, Bluetooth or wireless mode, and no receiver is needed or included. Earlier printed manuals mentioned a 2.5GHz wireless mode — that was a documentation error and has been corrected.
The keyboard is not detected.
Use a USB-C cable that supports data transfer, try another USB port, and close other keyboard software before connecting.
Does it work with macOS?
Yes. Both Apple silicon and Intel Macs are supported, and the macOS app is signed and notarized by Apple — it opens with a normal double-click.
Do I need the software?
No. The keyboard works plug-and-play. Install the driver only if you want per-key actuation, Rapid Trigger, macros or lighting control.
Which file should I download?
One Windows driver covers the S68. Mac users pick the Apple silicon or Intel build. The manual is device-specific — choose S68.
